# SQL Explorer

An interactive SQL learning laboratory where students write queries in **MySQL** or **Microsoft SQL Server (T-SQL)**, inspect detected SQL concepts and plain-language clause breakdowns, and reveal query results on demand.

## Repository Structure
- `frontend/` — React + TypeScript + Vite web application.
- `docs/` — Setup guide, frontend specification, and implementation notes.
- `backend/` *(planned)* — Express + TypeScript API, AST parser/validator, and evaluator.
- `database/` *(planned)* — Educational sample datasets (`university-demo-v1`).

## Quick Start
Run `cd frontend && npm install && cp .env.example .env && npm run dev`.
